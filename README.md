# Pass The Fear Backpack

这是一个面向《Pass the Fear》的 BepInEx IL2CPP Mod。当前版本提供独立背包，可存放秘宝、武器和武器配件。存入时内容会从游戏的装备数据移除，因此其属性不会参与角色计算；背包只保存普通 JSON 数据，不保留游戏对象引用。

## 当前功能

- `B` 打开或关闭使用游戏字体、面板和按钮资源绘制的原生 Unity UI 背包。
- 靠近地图上的武器、武器配件或秘宝时，拾取卡片会在 `E 拾取` 下方显示原生样式的 `F 存入背包`。
- 在 `Equipment` 页将秘宝、主副武器或武器配件存入背包。
- 在 `Stored` 页取出物品；武器、武器配件和秘宝都会按原版丢弃逻辑掉落在角色附近，不会直接装备。
- `Stored` 页的秘宝按每页 5 个显示，可使用原生样式的上一页和下一页按钮浏览。
- 使用游戏配置中的物品名称、图标、字体、面板和按钮资源绘制界面。
- 离线存入装备武器会同步清理运行时槽位和本局存档字典；联机存入由房主清理对应玩家实体。两者都不会调用武器丢弃接口，因此不会额外生成地面掉落物。
- 直接存入商店物品会先检查并扣除游戏要求的货币，不能绕过购买价格。
- 每次转移后调用游戏的属性刷新接口。
- `multiplayer-support` 分支允许每个安装同版本 Mod 的联机玩家使用自己的本轮背包，不再限制为房主本人。
- 客机只提交操作请求；房主从请求连接对应的真实玩家实体重新读取装备和物品，并负责移除、属性刷新与取出掉落。
- 房主按连接保存独立的临时保险库。取出只接受房主此前成功存入该连接保险库的条目，客户端 JSON 不能用于凭空生成物品。
- 联机世界物品会由房主重新验证实例、类型、距离和归属，必须属于请求玩家或已标记为共享。
- 操作使用唯一事务号并自动重试；房主会返回同一事务的缓存结果，避免响应丢失时重复删除或复制物品。
- 离线/联机切换、断线重连、房主身份或本地玩家索引变化时会清空本轮背包，避免跨房间串包。
- 支持存入最后一把武器；所有取出操作都会生成地面掉落，不要求预留装备空槽。
- 相同配置的多个秘宝会分别保存为独立背包条目，存入其中一个时只移除对应的一件。
- 从背包取出的武器带有原版掉落元数据，会参与关卡切换时的自动分解与清理。
- 使用带恢复状态的原子 JSON 存储，数据位于 `BepInEx/config/PassTheFearBackpack/storage-v1.json`。

普通消耗品、金币、剧情碎片、塔罗和秘宝锻造资源不会出现在可存列表中。

## 安装

1. 下载[BepInEx](https://github.com/BepInEx/BepInEx/actions/workflows/build.yml)，将其解压到游戏根目录
    1. 上面的链接指向BepInEx的最新build
    2. 进入链接后点击最新的构建，在页面最下方找到打包好的内容下载
    3. 解压到根目录，release中的版本过旧不支持当前游戏
2. 下载本仓库zip，将解压到的BepInEx文件夹整个复制到游戏根目录

## 多人模式

多人版本采用房主服务器权威模型。房主和普通客机都可以操作自己的背包，但装备移除、世界物品删除和取出掉落只在房主进程验证后执行，再通过游戏原有同步更新所有玩家。背包内容仍只对当前一轮游戏有效，换房、重连或开始新一轮都会清空。

`0.6.9` 同时支持游戏的局域网模式（LAN/LocalKcp）和 Steam 模式（SteamKcp/Multiplex）。两种模式共用服务器权威的 Mirror 消息协议；切换传输模式、重连或进入另一个同类型房间时都会重置本轮背包和网络事务，避免跨房间残留。

房主必须安装 `0.6.9`，需要使用背包的客机也必须安装相同版本。`0.6.9` 使用协议 v4，由主机根据稳定的物品数据和地图坐标解析自己的本地掉落实体，并在客户端确认原装备或地图掉落已经删除后才提交背包条目，不能与旧版混用。没有安装 Mod 的客机可以正常加入，但不能使用背包；不要让安装了该版本的客机连接未安装 Mod 的房主，因为房主没有对应的网络消息处理器。

`AllowMultiplayerTransfers` 默认开启。设为 `false` 可在本机禁用联机背包请求，离线背包不受影响。
